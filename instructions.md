

## Build & Development Commands

This project uses **Bun** (>=1.3.1) as its package manager and runtime.

- `bun dev` — Start Next.js dev server (Turbopack)
- `bun run build` — Generate mushaf assets + Next.js production build
- `bun run lint` — Run ESLint
- `bun run test:e2e` — Run Playwright e2e tests (builds and serves on port 3100)
- `bunx --bun playwright test tests/path/to/test.spec.ts` — Run a single e2e test
- `bun run generate:mushaf-assets` — Generate page JSON/protobuf from Quran.com API
- `bun run generate:mushaf-assets:sample` — Generate seed sample only
- `bun run fetch:qcf-fonts` — Download QCF WOFF2 fonts from CDN
- `bun run verify:mushaf-hashes` — Verify mushaf text integrity

## Architecture

### Tech Stack

Next.js 16 (App Router) + React 19 + TypeScript 5 + Tailwind CSS 4. Mobile-first PWA for reading the Quran. Path alias: `@/*` maps to `./src/*`.

### Routing

- `/` — Home page (reading history + surah/juz navigation)
- `/p/[page]?verse=surah:ayah` — Mushaf reader page (page 1-604, validated server-side)
- `/v/s/[surahId]` — Verse-by-verse mode (surah view)
- `/v/j/[juzId]` — Verse-by-verse mode (juz view)
- `/v/p/[page]` — Verse-by-verse mode (page view)
- `/m/[buckwalterLemma]` — Lemma lookup (Buckwalter-encoded)
- `/r/[buckwalterRoot]` — Root lookup (Buckwalter-encoded)

### State Management

No state library. All user state is persisted to **localStorage** and synced across components via `CustomEvent("preferences-changed")`. See `src/lib/preferences.ts` for read/write and `src/hooks/usePreferences.ts` for the hook.

URL state is **not** the source of truth — it's synced via `history.replaceState` (300ms debounce) for sharing/bookmarking only.

### Data Layer

- **Mushaf page data**: Static JSON files in `public/mushaf-data/{code}/p001-p604.json`. Loaded via `src/lib/mushaf/loader.ts`, cached in IndexedDB (`mushaf-pages` store).
- **QCF fonts** (v1, v2 mushafs only): Per-page WOFF2 fonts loaded via FontFace API, cached in IndexedDB (`mushaf-fonts` store). Adjacent pages preloaded (radius=2), far pages cleaned up (radius=5).
- **Translations**: Fetched from `api.quran.com/api/v4` or loaded from static JSON (`public/mushaf-data/data/abu-iyaad.json`), cached in IndexedDB (`translations` store).
- **Chapters**: Fetched from API, cached in-memory.

### Key Modules

- `src/components/reader/Reader.tsx` — Main reader orchestrator (preferences, theme, URL sync, history tracking)
- `src/components/mushaf/ScrollReader.tsx` — Scroll reading mode (5-page window, IntersectionObserver)
- `src/components/mushaf/SwipeReader.tsx` — Swipe reading mode (3-page window, CSS scroll-snap)
- `src/components/mushaf/MushafPage.tsx → MushafLine.tsx → MushafWord.tsx` — Page rendering hierarchy (all React.memo'd)
- `src/components/ayah/AyahSheet.tsx` — Verse detail modal (translation + copy)
- `src/lib/types.ts` — All TypeScript types and constants (mushaf codes, translations, themes)
- `src/lib/offline/` — IndexedDB storage, download management, offline status

### Mushaf System

Single mushaf code `v2` defined in `src/lib/types.ts`, using per-page QCF glyph fonts (WOFF2). Page data is generated by `scripts/generate-mushaf-assets.ts`.

### Offline / PWA

Service worker at `public/sw.js` uses cache-first for same-origin resources, network-first for external APIs. Content can be pre-downloaded to IndexedDB for full offline reading.

### Themes

3 themes (light-warm, dark-warm, white-green) applied via `data-theme` attribute on `<html>` with CSS custom properties defined in `src/app/globals.css`.
